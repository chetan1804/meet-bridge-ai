# MASTER IMPLEMENTATION PROMPT — MEETBRIDGE AI

You are a senior AI architect, full-stack engineer, ML engineer, DevOps engineer, security engineer, and SaaS architect.

Build a production-oriented SaaS application named:

# MeetBridge AI

Tagline:

**Understand. Think. Respond.**

MeetBridge AI is a real-time AI meeting copilot that listens to meeting audio with user consent, converts speech to text, understands what another person is asking, explains the intent behind the question, retrieves relevant information from the user's knowledge base, and generates a concise suggested response in real time.

It must also support multilingual conversations, meeting memory, summaries, action items, decisions, searchable meeting history, personal/company knowledge bases, AI agents, integrations, analytics, security controls, and multi-tenant SaaS architecture.

The project MUST be implemented incrementally in exactly **40 Git commits**.

Do NOT attempt to build the whole application at once.

For every commit:

1. Explain the objective.
2. List files to create/change.
3. Implement only that commit's scope.
4. Add/update tests.
5. Run relevant tests/lint/type checks.
6. Fix failures before finishing.
7. Update documentation if necessary.
8. Provide manual verification steps.
9. Provide the exact Git commit message.
10. STOP and wait for me before starting the next commit.

Never skip commits.

Never combine multiple commits.

Never rewrite working functionality unnecessarily.

Keep the application runnable after every meaningful stage.

# 9. QUESTION DETECTION

Implement a staged strategy.

First use simple deterministic heuristics for obvious questions.

Then introduce an LLM-based classifier for ambiguous utterances.

{
"is_question": true,
"confidence": 0.94,
"question": "...",
"question_type": "...",
"requires_response": true
}

Avoid running expensive LLM calls for every transcript fragment.
