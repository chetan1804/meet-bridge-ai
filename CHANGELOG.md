# Changelog

All notable changes to MeetBridge AI are documented here.

## [1.0.0] - 2026-10-07

### Added

- real-time meeting socket flow with auth and tenant guardrails
- meeting state, transcript, and question tracking
- knowledge retrieval and memory-aware context lookup
- AI evaluation dataset and scoring endpoints for retrieval and response quality
- security controls for audit logs, rate limiting, and secure uploads
- production runtime configuration validation
- Docker and CI scaffolding for backend and frontend
- architecture, release, security, and demo documentation

### Changed

- upgraded app metadata to v1.0.0 release state
- standardized internal API contracts for evaluation and meeting search

### Fixed

- critical path handling for end-to-end meeting and evaluation flow
- environment validation for production-safe startup
